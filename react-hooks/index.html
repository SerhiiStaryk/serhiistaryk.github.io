Вбудовані React Hooks

Hooks дозволяють використовувати різні можливості React у ваших компонентах. Ви можете використовувати вбудовані хуки або комбінувати їх для створення власних. На цій сторінці зібрано точну специфікацію всіх хуків із офіційної документації React 19.

Як влаштовані вбудовані хуки React

Згідно з офіційною документацією react.dev/reference/react ↗, функції, назви яких починаються з use, у React називаються хуками (Hooks).

1. Стан, Контекст та Посилання

useState та useReducer додають стан до компонента. useContext зчитує дані з контексту без передачі пропсів, а useRef зберігає мутабельні значення (наприклад, DOM-вузли), зміна яких не викликає повторний рендер.

2. Ефекти та Продуктивність

useEffect синхронізує компонент із зовнішніми системами. Хуки продуктивності (useMemo, useCallback, useTransition, useDeferredValue) допомагають уникати зайвих обчислень або не блокувати інтерфейс.

3. Новинки React 19 та API use

У React 19 з’явилися useActionState, useOptimistic, хук useFormStatus із пакета react-dom, а також вбудований API use(resource) для читання Promise та контексту навіть усередині умов.

Правила хуків (Rules of Hooks)

Офіційна сторінка Rules of Hooks ↗

Хуки визначаються за допомогою функцій JavaScript, але вони представляють особливий тип логіки інтерфейсу користувача з обмеженнями щодо того, де їх можна викликати.

1

Викликайте хуки лише на верхньому рівні

Не викликайте хуки всередині циклів, умовних операторів, вкладених функцій або блоків try/catch/finally. Завжди використовуйте хуки на верхньому рівні вашого компонента React перед будь-яким раннім поверненням (return).

  • ✓ Викликайте хуки на верхньому рівні тіла функціонального компонента.
  • ✓ Викликайте хуки на верхньому рівні власного хука (Custom Hook).
  • ✕ Не викликайте хуки всередині умов if або циклів for.
  • ✕ Не викликайте хуки в обробниках подій або всередині useMemo / useEffect.
2

Викликайте хуки лише з функцій React

Не викликайте хуки зі звичайних функцій JavaScript. Натомість ви можете викликати хуки лише з функціональних компонентів React або з власних хуків.

  • ✓ Викликайте хуки з функціональних компонентів React.
  • ✓ Викликайте хуки з власних хуків, назва яких починається з use.
  • ✕ Не викликайте хуки в класових компонентах React.
  • ✕ Не викликайте хуки у звичайних утилітарних функціях поза компонентами.
